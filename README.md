Entry for the make.fun bounty "One Word, One Username, One Reward": the program writes one word — the entrant's own make.fun username, `neha` — to `/output/entry.txt` and nothing else. Short, warm, and easy to remember: a name that lands in one word.

This writes exactly `neha` to `/output/entry.txt`, then reads it back and verifies it is within the gate (1–30 characters, not only whitespace, a single word).

## Run it

```sh
node main.ts
```
